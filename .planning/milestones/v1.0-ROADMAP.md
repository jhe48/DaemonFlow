# Milestone v1.0: MVP

**Status:** ✅ SHIPPED 2026-01-21
**Phases:** 1-8
**Total Plans:** 18

## Overview

Build a two-process productivity system: a Go daemon ("Heart") that invisibly monitors Git activity, file changes, and task completions to earn break time, paired with a Rust TUI ("Face") displaying an ASCII pet whose health reflects your productivity. Work earns freedom; slack kills pets.

## Phases

### Phase 1: Foundation

**Goal**: Working Go daemon that starts, runs persistently, and accepts IPC connections
**Depends on**: Nothing (first phase)
**Plans**: 2 plans

Plans:
- [x] 01-01: Core daemon structure (CLI, lifecycle, config) - Completed 2026-01-17
- [x] 01-02: Unix socket IPC server - Completed 2026-01-17

**Details:**
- Go module initialized with cobra CLI providing start/stop/status commands
- Daemon runs in background with PID file at ~/.daemonflow/daemonflow.pid
- Signal handling for graceful shutdown (SIGINT, SIGTERM)
- YAML configuration loading with sensible defaults
- IPC protocol with Request/Response types and length-prefixed JSON framing
- Unix socket server handling ping/status/stop/get_state requests

### Phase 2: Git Monitoring

**Goal**: Daemon detects and records Git activity in watched directory
**Depends on**: Phase 1
**Plans**: 2 plans

Plans:
- [x] 02-01: Git repo detection + commit/branch monitoring + daemon integration - Completed 2026-01-17
- [x] 02-02: Staged changes detection - Completed 2026-01-17

**Details:**
- Git repository detection with Repo struct (IsGitRepo, GetHEAD, GetBranch, GetLastCommitTime)

## Milestone Summary

**Key Decisions:**
- Go for daemon, Rust for TUI — Clean separation, both languages played to strengths
- Git CLI over go-git — Simpler, lighter, no complex dependency
- fsnotify for file watching — Standard Go library, worked well
- 500ms debounce for file events — Reduces spam without losing events
- Length-prefixed JSON IPC — Simple, debuggable, sufficient performance
- Cat-based ASCII pet — Clear emotional states, fits terminal well
- 5-minute overtime death threshold — Enough warning time while maintaining stakes
- Resurrection cost forfeits all earned time — Maintains stakes while allowing recovery
