  <name>Task 1: Define IPC protocol</name>
  <files>internal/ipc/protocol.go</files>
  <action>
    1. Create internal/ipc/protocol.go with message types:
       - Request struct: Type string, Payload json.RawMessage
       - Response struct: Success bool, Error string, Data json.RawMessage
    2. Define request types as constants:
       - "ping" - health check
       - "status" - get daemon status
       - "stop" - request graceful shutdown
       - "get_state" - get current productivity state (for TUI)
    3. Define response data types:
       - StatusResponse: Running bool, Uptime int64, WatchDir string
       - StateResponse: placeholder struct for clock/activity data
    4. Use JSON encoding (simple, debuggable, fast enough for this use case)
    5. Frame messages with 4-byte length prefix (uint32 big-endian) for reliable reading

<task type="auto">
  <name>Task 2: Implement IPC server in daemon</name>
  <files>internal/ipc/server.go, internal/daemon/daemon.go</files>
  <action>
    1. Create internal/ipc/server.go with Server struct:
       - socketPath string
       - listener net.Listener
       - daemon *Daemon (back-reference to handle requests)
       - Methods: Start(), Stop(), handleConnection(conn net.Conn)
    2. Server.Start():
       - Remove existing socket file if present (stale from crash)
       - Create Unix socket listener at socketPath
       - Accept connections in goroutine
       - For each connection, spawn handleConnection goroutine
    3. handleConnection():
       - Read length-prefixed JSON request
       - Route to handler based on Type
       - Send length-prefixed JSON response
       - Close connection after response (simple request-response, not persistent)
    4. Implement handlers:
       - ping: return success
       - status: return StatusResponse with uptime, watchdir
       - stop: set daemon shutdown flag, return success
    5. Update Daemon struct to hold *ipc.Server
    6. Start IPC server in Daemon.Start(), stop in Daemon.Stop()
    7. Clean up socket file on shutdown
  </action>
  <verify>
    ./cmd/daemonflow/daemonflow start
    ls ~/.daemonflow/daemonflow.sock
    ./cmd/daemonflow/daemonflow stop
  </verify>
  <done>Daemon creates socket on start, removes on stop</done>
</task>
