<task type="auto">
  <name>Task 1: Git repository detection and state reading</name>
  <files>internal/git/repo.go</files>
  <action>
    1. Create internal/git/repo.go with Repo struct:
       - path string (repo root directory)
       - Methods: IsGitRepo() bool, GetHEAD() (string, error), GetBranch() (string, error), GetLastCommitHash() (string, error), GetLastCommitTime() (time.Time, error)
    2. IsGitRepo checks for .git directory existence
    3. Shell out to git for queries (simpler than go-git library):
       - `git rev-parse HEAD` for current commit
       - `git symbolic-ref --short HEAD` for branch name
       - `git log -1 --format=%ct` for last commit timestamp
    4. Handle errors gracefully (repo not initialized, detached HEAD, etc.)
    5. Add helper function: FindGitRoot(path string) (string, error) - walks up to find .git
  </action>
  <verify>go build ./internal/git/... && go vet ./internal/git/...</verify>
  <done>Repo struct can detect git repos and read HEAD/branch/commit info</done>
</task>

<task type="auto">
  <name>Task 2: Git monitor with polling and change detection</name>
  <files>internal/git/monitor.go, internal/activity/activity.go</files>
  <action>
    1. Create internal/activity/activity.go with activity types:
       - ActivityType enum: GitCommit, GitBranchSwitch, FileChange, TaskComplete
       - Activity struct: Type, Timestamp, Details map[string]string
       - ActivityListener interface: OnActivity(Activity)
    2. Create internal/git/monitor.go with Monitor struct:
       - repo *Repo
       - pollInterval time.Duration (default 5s from config)
       - lastCommit string, lastBranch string
       - listeners []ActivityListener
       - Methods: Start(ctx context.Context), Stop(), AddListener(ActivityListener)
    3. Monitor.Start() polls in goroutine:
       - Every pollInterval, check HEAD and branch
       - If commit changed: emit GitCommit activity with hash, message preview
       - If branch changed: emit GitBranchSwitch with old/new branch names
       - Use context for cancellation
    4. Make poll interval configurable in config.yaml:
       ```yaml
       git:
         poll_interval: 5s
       ```
    5. Update internal/config/config.go to include Git config section
  </action>
  <verify>go build ./internal/... && go vet ./internal/...</verify>
  <done>Monitor detects commits and branch switches, emits Activity events</done>
</task>
