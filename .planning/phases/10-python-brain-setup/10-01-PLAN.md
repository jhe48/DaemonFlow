  <name>Task 1: Create Python brain package structure</name>

  <action>
Create `brain/` directory at project root with:

1. `brain/__init__.py` - Package marker, export version string
   - `__version__ = "0.1.0"`

2. `brain/main.py` - CLI entry point
   - Use argparse for CLI parsing
   - Accept `--action` flag (required) to specify operation
   - Accept `--input` flag for JSON string input OR read from stdin if not provided
   - Output JSON to stdout
   - For now, implement a single "echo" action that returns the input unchanged (placeholder for Phase 11)
   - Exit code 0 on success, 1 on error
   - On error, output JSON with `{"error": "message"}` to stdout

Example usage:
```bash
python -m brain --action echo --input '{"test": "data"}'
# Output: {"test": "data"}
```

AVOID: External dependencies (no pip install). Use only Python stdlib (argparse, json, sys).

<task type="auto">
  <name>Task 2: Create Go executor package</name>
  <files>internal/brain/executor.go, internal/brain/executor_test.go</files>
  <action>
Create `internal/brain/` package with:

1. `internal/brain/executor.go`:
   - `type Executor struct` with configurable python path (default: "python3")
   - `func NewExecutor() *Executor` - constructor
   - `func (e *Executor) Execute(ctx context.Context, action string, input interface{}) (json.RawMessage, error)` method:
     - Marshal input to JSON
     - Build command: `python3 -m brain --action {action} --input {json}`
     - Set working directory to project root (need to detect or accept as config)
     - Execute via exec.CommandContext
     - Capture stdout and stderr
     - If exit code != 0, return error with stderr content
     - Parse stdout as JSON, return as json.RawMessage
   - `func (e *Executor) SetPythonPath(path string)` - override python binary
   - `func (e *Executor) SetBrainDir(dir string)` - set directory containing brain package

2. `internal/brain/executor_test.go`:
   - Test Execute with echo action
   - Test Execute with invalid action (expects error)
   - Test Execute with malformed input

Design notes:
- Use `exec.CommandContext` for timeout/cancellation support
- Combine stdout/stderr for error reporting
- JSON input passed via --input flag (not stdin) for simplicity
- Return json.RawMessage to let caller decode as needed

AVOID: Global state. Keep executor instance-based for testability.
