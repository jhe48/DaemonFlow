<task type="auto">
  <name>Task 2: Add `add` subcommand to CLI</name>
  <files>cmd/daemonflow/main.go</files>
  <action>
Add `add` command to cobra CLI in main.go:

1. Create addCmd:
   ```go
   var addCmd = &cobra.Command{
       Use:   "add [task text]",
       Short: "Add a task",
       Long:  `Add a task to TASKS.md in the current directory. The daemon will automatically sync it.`,
       Args:  cobra.MinimumNArgs(1),
       RunE:  runAdd,
   }
   ```

2. Implement runAdd function:
   - Join args with space to get full task text: `text := strings.Join(args, " ")`
   - Get current working directory
   - Construct TASKS.md path: `filepath.Join(cwd, "TASKS.md")`
   - Append task to file:
     - If file doesn't exist, create with "# Tasks\n\n" header
     - Append `- [ ] {text}\n` to file
   - Get task count from daemon via IPC (handle daemon not running gracefully)
   - Print confirmation with color using ANSI codes:
     - Green checkmark: `\033[32m✓\033[0m`
     - Format: `✓ Added: {text} ({count} tasks)`
     - If daemon not running, omit count: `✓ Added: {text}`

3. Add to rootCmd: `rootCmd.AddCommand(startCmd, stopCmd, statusCmd, activitiesCmd, addCmd)`

Style notes:
- Use simple ANSI escape codes for color (no external library)
- Keep output single-line, clean like gh CLI
- Handle errors gracefully: if file write fails, print error to stderr and exit 1
  </action>
