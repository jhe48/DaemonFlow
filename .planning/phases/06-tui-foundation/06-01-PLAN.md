<task type="auto">
  <name>Task 2: Implement terminal setup and cleanup</name>
  <files>tui/src/terminal.rs</files>
  <action>
Create terminal.rs with functions:
- setup() -> Result<Terminal<CrosstermBackend<Stdout>>>: Enable raw mode, enter alternate screen, create terminal with CrosstermBackend
- cleanup(terminal: &mut Terminal<...>) -> Result<()>: Disable raw mode, leave alternate screen, show cursor
- install_panic_hook(): Set panic hook that calls cleanup before panicking (prevents terminal corruption on crash)

Use crossterm::terminal::{enable_raw_mode, disable_raw_mode, EnterAlternateScreen, LeaveAlternateScreen}.
Use crossterm::execute! macro for terminal commands.
Use std::panic::set_hook for panic handler.
  </action>
  <verify>cd tui && cargo build && cargo clippy</verify>
  <done>terminal.rs compiles with no warnings, functions are public</done>
</task>

<task type="auto">
  <name>Task 3: Create basic App struct and event loop</name>
  <files>tui/src/app.rs, tui/src/main.rs</files>
  <action>
Create app.rs with:
- App struct with fields: running: bool
- impl App: new() -> Self, quit(&mut self)
- run(&mut self, terminal: &mut Terminal<...>) -> Result<()>:
  - Loop while self.running
  - terminal.draw(|frame| self.render(frame))
  - Poll for events with crossterm::event::poll(Duration::from_millis(100))
  - If event available, read with crossterm::event::read()
  - Handle KeyCode::Char('q') or KeyCode::Esc to call self.quit()
- render(&self, frame: &mut Frame): Draw a simple "DaemonFlow TUI - Press q to quit" centered text

Update main.rs:
- Call terminal::install_panic_hook()
- let mut terminal = terminal::setup()?
- let mut app = App::new()
- app.run(&mut terminal)?
- terminal::cleanup(&mut terminal)?

Use ratatui::widgets::{Block, Paragraph} for rendering.
Use ratatui::layout::{Layout, Constraint, Direction} if needed.
  </action>
  <verify>cd tui && cargo run (then press 'q' to exit cleanly)</verify>
  <done>TUI shows message, responds to 'q' key, terminal restores correctly on exit</done>
</task>
