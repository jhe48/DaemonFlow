  <name>Task 1: Create task sync engine with priority scoring</name>
  <files>internal/task/sync.go</files>
  <action>
Create new file internal/task/sync.go with:

```go
type TaskSync struct {
    store *store.Store
}

func NewTaskSync(s *store.Store) *TaskSync

// SyncDirectory parses TASKS.md from directory and syncs all tasks to SQLite.
// Returns number of tasks synced and any error.
func (ts *TaskSync) SyncDirectory(dirPath string) (int, error)
```

SyncDirectory logic:
1. Build taskFilePath = filepath.Join(dirPath, "TASKS.md")
2. Parse file using existing task.ParseFile()
3. For each parsed task:
   - Create store.Task with ProjectPath=dirPath, Text=task.Text, Completed=task.Completed
   - Compute PriorityScore using computePriority() helper
   - Call store.InsertTask() (upsert behavior)
4. Delete stale tasks: tasks in DB for this project_path that weren't in the parsed file

computePriority(task, dirPath) logic:
- Base score: 0
- Has due date: +100 if due within 24h, +50 if due within 7d, +25 otherwise
- Task age: +1 for each day since creation (older = higher priority, up to +30)
- Project activity: (future enhancement - for now, skip)
Return computed score as int.

Handle file-not-found gracefully: if TASKS.md doesn't exist, delete all tasks for that project_path from DB (project removed).
