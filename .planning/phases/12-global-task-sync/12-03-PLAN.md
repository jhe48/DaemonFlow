<task type="auto">
  <name>Task 1: Update daemon to manage multiple task trackers</name>
  <files>internal/daemon/daemon.go</files>
  <action>
Modify daemon.go:

1. Change `taskTracker *task.TaskTracker` to `taskTrackers []*task.TaskTracker`

2. Update startTaskTracker() → startTaskTrackers(ctx context.Context) error:
   - Iterate over d.Config.GetWatchDirs()
   - For each directory, create a TaskTracker with filepath.Join(dir, "TASKS.md")
   - Start each tracker, add daemon as listener
   - Append to d.taskTrackers slice
   - Log "Task tracker monitoring: {N} directories"

3. Update stopTaskTracker() → stopTaskTrackers():
   - Iterate over d.taskTrackers and stop each

4. Add taskSync field: `taskSync *task.TaskSync`
   - Initialize after store is opened: `d.taskSync = task.NewTaskSync(d.store)`
   - On daemon start, do initial sync for all directories:
     ```go
     for _, dir := range d.Config.GetWatchDirs() {
         if _, err := d.taskSync.SyncDirectory(dir); err != nil {
             log.Printf("Warning: initial task sync failed for %s: %v", dir, err)
         }
     }
     ```

5. Add new method to handle task file changes:
   ```go
   func (d *Daemon) OnTaskFileChanged(dir string) {
       if d.taskSync != nil {
           if count, err := d.taskSync.SyncDirectory(dir); err != nil {
               log.Printf("Task sync error for %s: %v", dir, err)
           } else {
               log.Printf("Synced %d tasks from %s", count, dir)
           }
       }
   }
   ```
  </action>

  <done>Daemon manages multiple TaskTrackers, syncs on startup</done>
</task>
