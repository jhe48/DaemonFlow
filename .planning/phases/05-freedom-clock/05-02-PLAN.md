Create clock.go in internal/clock with:

```go
type ClockState string

const (
    StateWorking  ClockState = "working"   // User actively working, earning time
    StateBreak    ClockState = "break"     // User on break, time counting down
    StateOvertime ClockState = "overtime"  // Break time exhausted, in debt
)

type Clock struct {
    state          ClockState
    earnedSeconds  int           // Total earned seconds (can go negative in overtime)
    earning        *EarningCalculator
    mu             sync.RWMutex
    ticker         *time.Ticker
    stopChan       chan struct{}
}

func NewClock(earningCfg *config.EarningConfig) *Clock

// Start begins the clock ticker (1-second resolution)
func (c *Clock) Start()

// Stop halts the clock ticker
func (c *Clock) Stop()

// OnActivity processes an activity and adds earned time
func (c *Clock) OnActivity(act activity.Activity)

// StartBreak transitions to break state
func (c *Clock) StartBreak()

// EndBreak transitions back to working state
func (c *Clock) EndBreak()

// GetState returns current clock state
func (c *Clock) GetState() ClockState

// GetEarnedSeconds returns current earned seconds balance
func (c *Clock) GetEarnedSeconds() int
```

Clock behavior:
- In StateWorking: OnActivity adds earned seconds, ticker does nothing
- In StateBreak: Ticker decrements earnedSeconds every second
- When earnedSeconds reaches 0 during break: Transition to StateOvertime
- In StateOvertime: Continue decrementing (goes negative)
- EndBreak always returns to StateWorking regardless of current state

The clock implements activity.ActivityListener via OnActivity.
