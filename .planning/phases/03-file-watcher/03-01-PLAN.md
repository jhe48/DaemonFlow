<task type="auto">
  <name>Task 1: Add fsnotify dependency and ignore pattern matcher</name>
  <files>go.mod, internal/watcher/ignore.go</files>
  <action>
    1. Add fsnotify dependency: `go get github.com/fsnotify/fsnotify`
    2. Create internal/watcher/ignore.go with IgnoreMatcher:
       - Default patterns: .git, .git/**, node_modules, node_modules/**, *.swp, *.swo, *~, .DS_Store, __pycache__, *.pyc, .idea, .vscode, *.log, dist, build, target, vendor
       - Match(path string) bool - returns true if path should be ignored
       - Use filepath.Match for glob patterns
       - Support ** for recursive directory matching (manual implementation)
       - AddPattern(pattern string) to add custom patterns
       - Patterns are relative to watch root
  </action>
  <verify>go build ./internal/watcher/... && go vet ./internal/watcher/...</verify>
  <done>IgnoreMatcher filters common noise patterns</done>
</task>

<task type="auto">
  <name>Task 2: Create file watcher with fsnotify</name>
  <files>internal/watcher/watcher.go</files>
  <action>
    1. Create internal/watcher/watcher.go with Watcher struct:
       - root string (directory to watch)
       - watcher *fsnotify.Watcher
       - ignore *IgnoreMatcher
       - listeners []activity.ActivityListener
       - Methods: Start(ctx context.Context) error, Stop(), AddListener(activity.ActivityListener)
    2. Start():
       - Create fsnotify watcher
       - Recursively add all directories under root (excluding ignored)
       - Start goroutine to handle events
       - Use context for cancellation
    3. Event handling goroutine:
       - Filter events through IgnoreMatcher
       - For Create/Write/Remove events on non-ignored paths:
         - Emit FileChange activity with details: "path" (relative to root), "operation" (create/modify/delete)
       - For Create of directories: add to watcher (recursive watching)
       - For Remove of directories: handled automatically by fsnotify
    4. Handle fsnotify errors gracefully (log and continue)
  </action>
  <verify>go build ./internal/watcher/... && go vet ./internal/watcher/...</verify>
  <done>Watcher emits FileChange activities for non-ignored files</done>
</task>
