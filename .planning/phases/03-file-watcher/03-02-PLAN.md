  <files>internal/watcher/debounce.go, internal/watcher/watcher.go</files>
  <action>
    1. Create internal/watcher/debounce.go with Debouncer:
       - pendingEvents map[string]*PendingEvent (keyed by file path)
       - debounceWindow time.Duration (default 500ms)
       - mu sync.Mutex
       - timer *time.Timer
       - callback func(events []FileEvent)
    2. PendingEvent struct: Path, Operation (latest), FirstSeen, LastSeen
    3. Debouncer.Add(event FileEvent):
       - Lock mutex
       - If path exists in pending: update LastSeen and Operation (use latest)
       - If path not in pending: add with FirstSeen = LastSeen = now
       - Reset/start timer for debounceWindow
       - On timer fire: flush all pending events via callback, clear map
    4. Debouncer.Flush(): force immediate flush (for shutdown)
    5. Update Watcher to use Debouncer:
       - Instead of emitting immediately, add to debouncer
       - Debouncer callback emits batched FileChange activity
       - Activity details: "file_count", "files" (comma-separated, max 5), "operations" (unique ops)
  </action>
  <verify>go build ./internal/watcher/... && go vet ./internal/watcher/...</verify>
  <done>Rapid file changes aggregated into single activity emission</done>
