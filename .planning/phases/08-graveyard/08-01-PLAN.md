<task type="auto">
  <name>Task 2: Add death detection to Clock</name>
  <files>internal/clock/clock.go</files>
  <action>
Add death detection to Clock:

1. Add constant: DeathThresholdSeconds = -300 (match TUI's DEATH_THRESHOLD_SECONDS)

2. Add field to Clock: deathTriggered bool (prevents multiple death events)

3. Add callback field: OnDeath func(overtimeSeconds int, sessionEarned int)

4. In tick() for StateOvertime case, after decrementing:
   - Check if earnedSeconds <= DeathThresholdSeconds && !deathTriggered
   - If true, set deathTriggered = true, call OnDeath if set

5. In EndBreak(), reset deathTriggered = false (allows death again if user goes back to overtime)

This keeps Clock focused on state management while daemon can handle the death callback.
  </action>
  <verify>go build ./internal/clock/...</verify>
  <done>Clock has DeathThresholdSeconds constant, OnDeath callback, fires once on reaching threshold</done>
</task>

<task type="auto">
  <name>Task 3: Integrate graveyard with daemon</name>
  <files>internal/daemon/daemon.go</files>
  <action>
Wire graveyard into daemon:

1. Add import for graveyard package

2. Add field to Daemon: graveyard *graveyard.Graveyard

3. In NewDaemon or Start(), create graveyard: d.graveyard = graveyard.NewGraveyard(d.config.DataDir)

4. Set clock's OnDeath callback to log death:
   d.clock.OnDeath = func(overtimeSeconds int, sessionEarned int) {
       record := graveyard.DeathRecord{
           Timestamp: time.Now(),
           OvertimeSeconds: -overtimeSeconds, // Convert negative to positive
           SessionEarned: sessionEarned,
           Cause: "overtime",
       }
       if err := d.graveyard.LogDeath(record); err != nil {
           // Log error but don't crash - death logging is not critical
           log.Printf("Failed to log death: %v", err)
       }
   }

5. Load existing records on startup: d.graveyard.LoadRecords() (ignore error if file doesn't exist)
  </action>
  <verify>go build ./cmd/daemonflow/... && go build ./internal/daemon/...</verify>
  <done>Daemon creates graveyard, wires death callback, logs deaths to GRAVEYARD.md</done>
</task>
