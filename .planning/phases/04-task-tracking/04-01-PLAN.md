<task type="auto">
  <name>Task 1: Create task file parser</name>
  <files>internal/task/parser.go</files>
  <action>
Create TaskParser in `internal/task/parser.go` with:

1. **Task struct** to represent a single task:
   - `Line int` - line number in file (1-indexed)
   - `Text string` - task text without checkbox
   - `Completed bool` - whether checkbox is checked

2. **ParseFile(path string) ([]Task, error)** function:
   - Read file contents
   - Parse each line looking for markdown checkbox patterns
   - Support both `- [ ]` (unchecked) and `- [x]` / `- [X]` (checked)
   - Extract task text (trimmed, without the checkbox prefix)
   - Return slice of Task structs

3. **ParseContent(content string) []Task** function:
   - Same parsing logic but takes string content
   - Useful for testing and for comparing old vs new state

Pattern matching:
- Regex: `^\s*-\s*\[([ xX])\]\s*(.+)$`
- Group 1: space = unchecked, x/X = checked
- Group 2: task text

Edge cases:
- Empty lines: skip
- Lines without checkbox: skip
- Multiple spaces before dash: allow (nested tasks)
- Empty task text: skip

Follow existing code style from watcher package (error handling, logging).
